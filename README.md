The zip contains `AutoMailer.exe` plus its runtime folder — unpack it somewhere
permanent (not `Downloads`) and run the exe.

## First run

1. Windows may show *"unrecognised app"* → **More info → Run anyway** (the exe is not code-signed).
2. The licence window opens: paste the same `AUTOMAILERPANEL-…` key, press **Activate**.
   The key binds to that PC (HWID `xxxx-xxxx-xxxx-xxxx`, shown in the window).
3. Pick the mail provider, set the account count and press **Start**.

## Updating

The app checks this repository on launch (**Check for updates** on the licence
window) and can download + swap itself. Keep the app folder together: the
updater replaces `AutoMailer.exe` in place and leaves the previous build as
`AutoMailer.old`.

## Notes

* One licence key = the number of PCs your plan allows; moving to a new PC needs a reset.
* Sessions/cookies are saved next to the exe in `cookies\`.
* Logs stay local in `auto_mailer.log`.
